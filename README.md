# Restaurant Sales Analytics using Python and Power BI

## Project Overview

This project presents a complete sales analysis workflow for a restaurant using real-world transaction data.

The project covers the entire data analysis process, including:

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Quarterly Sales Analysis
- Full-Year Sales Analysis
- Business Insights
- Interactive Power BI Dashboard

The analysis aims to understand customer purchasing behavior, identify sales trends, evaluate product performance, and provide business insights that support data-driven decision-making.
