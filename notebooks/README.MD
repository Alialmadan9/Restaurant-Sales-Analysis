# Notebooks

This folder contains all Jupyter notebooks used throughout the project, covering both the data cleaning process and the exploratory data analysis (EDA).

### Q1_cleaning.ipynb
Data cleaning and preprocessing for Quarter 1.

### Q2_cleaning.ipynb
Data cleaning and preprocessing for Quarter 2.

### Q3_cleaning.ipynb
Data cleaning and preprocessing for Quarter 3.

### Q4_cleaning.ipynb
Data cleaning and preprocessing for Quarter 4.

During the cleaning process, the following tasks were performed:

- Handling missing values
- Removing duplicate records
- Correcting data types
- Standardizing column names
- Validating data quality
- Preparing the data for analysis
